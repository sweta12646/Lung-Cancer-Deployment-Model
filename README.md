
# 🫁 Lung Cancer Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on building a Machine Learning model for Lung Cancer Classification using Python.

The project uses the Lung Cancer Survey Dataset to analyze different health-related factors and develop classification models.

The trained model is deployed using Streamlit to create an interactive and user-friendly web application.

## 🎯 Project Objectives

- Analyze the Lung Cancer dataset.
- Perform data preprocessing and cleaning.
- Train multiple Machine Learning classification algorithms.
- Compare model performance.
- Select and save a trained model.
- Deploy the model using Streamlit.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Joblib
- Jupyter Notebook

## 🤖 Machine Learning Algorithms

The project explores the following classification algorithms:

- Decision Tree Classifier
- Random Forest Classifier
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gradient Boosting Classifier

## 📊 Model Evaluation

The models are compared using:

- Accuracy
- Precision
- Recall
- F1 Score

Actual evaluation results are available in the model comparison file.

## 🌐 Streamlit Web Application

The project includes an interactive Streamlit application with:

- Dark Mode Dashboard
- Health Assessment Form
- Lung Cancer Classification Prediction
- Model Performance Comparison
- About Project Section
